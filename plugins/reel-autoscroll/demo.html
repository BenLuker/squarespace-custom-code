reel-autoscroll

Mimics two native Squarespace "Slideshow: Reel" gallery sections below. The plugin finds anything carrying sqcc-reel-auto (the class an editor would add via the Section's own Custom CSS Class field), hides the native reel, and replaces it with a continuously auto-scrolling, drag-to-scrub ribbon built on Embla.

Section 1: just sqcc-reel-auto — every other option stays at its default.

Section 2: sqcc-reel-auto sqcc-reel-speed-90 sqcc-reel-dir-right sqcc-reel-dots sqcc-reel-no-controls sqcc-reel-radius-16 — faster, scrolls right, dots instead of arrows, rounded corners, and set to an inset (not full-bleed) width to confirm the ribbon respects that too.

Rest of the page

Content flows normally below. Drag either ribbon and confirm it holds once you let go — resume waits for the drag's own momentum to fully settle before the resume-delay hold starts, so it never fights an in-flight release glide or snap.
