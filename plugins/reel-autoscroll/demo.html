reel-autoscroll

Mimics two native Squarespace "Slideshow: Reel" gallery sections below. The plugin finds every .gallery-reel, checks its section's own data-section-id for a --sqcc-reel-auto: 1 CSS custom property (set via a scoped rule in Design → Custom CSS on the real site — see the <style> block above), hides the native reel, and replaces it with a continuously auto-scrolling, drag-to-scrub ribbon built on Embla.

Section 1: just --sqcc-reel-auto: 1 — every other option stays at its default.

Section 2: speed 90, scrolls right, dots instead of arrows, rounded corners, and set to an inset (not full-bleed) width to confirm the ribbon respects that too.

Rest of the page

Content flows normally below. Drag either ribbon and confirm it holds once you let go — resume waits for the drag's own momentum to fully settle before the resume-delay hold starts, so it never fights an in-flight release glide or snap.
