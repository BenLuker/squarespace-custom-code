On Squarespace this sits as the first Code Block in the first full-width Section of a Page (title hidden) — full-bleed and behind the nav come free from that placement, not from anything in this demo page. Below, the banner breaks out edge-to-edge from this centered column on its own via data-full-bleed, same trick it'll rely on there.

Banner 1 (data-snap="true", default): drag and release — the nearest image snaps to the left edge and holds, then resumes.

Banner 2 (data-snap="false"): drag and release — it glides to a stop via momentum, no forced alignment to any image.

Banner 3 (data-height="auto"): fills the height of its containing Fluid Engine block (here mocked as a 400px-tall .fe-block) instead of a fixed px value — on Squarespace, resizing the block's own resize handles is what controls this banner's height.
